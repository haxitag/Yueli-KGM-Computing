沙箱调用

            

                sandbox.html 与下方 API / 工具共用同一套 /v1/kgm/sandboxes 控制面，
                创建 / 列表 / 停止始终有效；
                启动需配置外部 adapter，否则返回 503 sandbox_adapter_required
                （当前默认 runtimeMode=unconfigured，并非假启动的 simulated）。
            

        

        

            

                
1. 控制台

                
顶部导航「沙箱」打开独立页，可创建 computer / browser / mobile 并启停。

                
打开 sandbox.html →

                
正在探测 adapter 状态…

            

            

                
2. HTTP API

                
curl http://127.0.0.1:3000/v1/kgm/sandboxes

curl -X POST http://127.0.0.1:3000/v1/kgm/sandboxes \
  -H 'Content-Type: application/json' \
  -d '{"kind":"browser","name":"demo-browser"}'

curl -X POST http://127.0.0.1:3000/v1/kgm/sandboxes/<id>/start
curl -X POST http://127.0.0.1:3000/v1/kgm/sandboxes/<id>/stop

            

            

                
3. 对话内置工具

                
开启「内建能力」后，模型可调用：

                
    
                    
  • list_sandboxes — 列表与预览
    • 
                    
  • start_sandbox — {"id":"sbx_…"}
    • 
                    
  • stop_sandbox — {"id":"sbx_…"}
    • 
                

                
未配置 adapter 时 start_sandbox 同样会失败并返回配置提示。

            

            

                
4. 启用真实 runtime

                
# 浏览器（Playwright）
export KGM_SANDBOX_BROWSER_USE_EMBEDDED=1
# 或显式命令 / WS：
# KGM_SANDBOX_BROWSER_START_CMD / STOP_CMD / STATUS_CMD
# KGM_SANDBOX_BROWSER_WS_ENDPOINT

# 虚拟机（QEMU）
export KGM_SANDBOX_COMPUTER_USE_EMBEDDED=1
export KGM_SANDBOX_VM_IMAGE="/abs/path/disk.qcow2"

# 移动端（Android Emulator）
export KGM_SANDBOX_MOBILE_USE_EMBEDDED=1
export ANDROID_AVD_NAME="Pixel_8_API_35"

                
详见 docs/deployment-and-api.md § Sandbox adapters。

技能定义在下方 JSON 的 skills；激活靠把技能 id 写入 activeSkillIds 后点「保存到服务端」。

                
    
                    
  1. 点「从服务端加载」，在 JSON 里找到目标技能的 id（默认演示：skill-weather-demo）。
    2. 
                    
  2. 设置 "activeSkillIds": ["skill-weather-demo"]（可多个）。
    3. 
                    
  3. 点「保存到服务端」→ 对话区开启「内建能力」；模型会收到技能提示，并通过 invoke_skill 执行步骤。
    4. 
                    
  4. 演示天气技能另需环境变量 OPENWEATHER_API_KEY；纯提示型技能只需激活即可。
    5. 
                

                

                    
                    
                    
                

            

            

                
MCP 连接器 = 本机或外网的 HTTP JSON-RPC 完整 URL（如 http://127.0.0.1:3100/mcp）。当前运行时仅支持 HTTP POST，不支持原生 SSE / stdio 传输。

                
    
                    
  1. 在 JSON 的 mcpConnectors 增加一项：id、name、enabled: true、transport: "http"、url（必填完整端点）。
    2. 
                    
  2. 把该 id 写入 activeMcpIds，再点「保存到服务端」（保存按钮在「技能」子页也可）。
    3. 
                    
  3. 对话开启「内建能力」后，模型通过工具 mcp_call（参数 connectorId / toolName / arguments）调用远端工具。
    4. 
                    
  4. 若上游只有 SSE MCP，需先用网关转成可 POST 的 HTTP JSON-RPC；纯 SSE URL 填入会失败。
    5. 
                

            

            

                
输出模版支持 {{变量名}} 插槽；常用 {{content}} 为模型原文。
